# 🎮 坦克大战 (Tank Battle)

一个使用纯 HTML/CSS/JavaScript 制作的经典坦克大战游戏，可直接在浏览器中运行。

## 🎯 游戏特色

- 🎨 **经典复刻** — 致敬经典FC坦克大战，包含砖墙、钢墙、水域、基地等元素
- 🎯 **3个关卡** — 难度递增，每关地图不同
- 💪 **道具系统** — 星星(强化子弹)、护盾、炸弹(全屏消灭)、时钟(冻结敌人)、生命
- 🤖 **AI敌人** — 敌人会追踪玩家、躲避障碍物、主动射击
- 🗺️ **小地图** — 右下角实时小地图显示敌我位置
- 💥 **特效系统** — 爆炸粒子、屏幕震动、闪烁效果
- ⏸️ **暂停功能** — 按 P 键暂停/继续

## 🕹️ 操作说明

| 按键 | 功能 |
|------|------|
| `↑ ↓ ← →` 或 `WASD` | 移动坦克 |
| `空格键` | 发射炮弹 |
| `P` | 暂停/继续 |
| `R` | 重新开始（游戏结束后） |

## 🚀 快速开始

1. 克隆仓库
```bash
git clone https://github.com/zhm1314/tank-battle.git
```

2. 直接用浏览器打开 `index.html` 即可开始游戏
